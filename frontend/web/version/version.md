# 版本记录

## 未发布

## v3.0.1（2026-11-27）

- 流程配音移除 MiniMax 音色，已生成的音频和视频仍可播放。

### 新增

- 流程角色和自由画布支持跨项目使用个人原录音，可试听、改名和修改头像。流程视频的角色音频引用使用其实际绑定的录音。

- 剧本成片的图生与自动宫格支持在分镜脚本和分镜图中选用多张参考图，可从「灵感空间」导入角色、场景和道具。刷新页面后可恢复已提交的提示词和参考图。
- 音画同步支持直接上传原录音并用于对口型，提交前可查看费用。
- 桌面和移动首页支持展示备案号，并链接到工信部备案查询。

### 优化

- 个人音色使用单栏录音上传弹窗，选中文件后可直接更换。头像大小上限读取公共上传配置。
- 自由画布的文本、生图和视频节点显示各自业务已配置的型号，并优先选中默认型号。

- 自由画布按所选模型提示输入、参考素材和报价问题，可以定位出错的参考图。每个视频节点支持连接一个参考视频，添加多个时会提示。
- 自由画布的助手设置明确区分本轮和后续预算。Skill 列表跟随主题并支持滚动加载。
- 分镜视频生成区直接展示报价失败原因和模型输入限制。

### 修复

- 修复分镜图生成完成后仍显示加载的问题。生成结果会自动显示在分镜页和编辑弹窗。
- 修复自由画布「整组执行」无法运行组内图片节点的问题。执行后可逐个查看节点结果和失败原因。
